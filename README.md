# Сайт Пермского стендап клуба — permstandup.ru

Статический сайт на [Astro](https://astro.build). Своего сервера нет: сайт собирается в набор HTML-файлов и выкладывается на хостинг.

## Как посмотреть сайт у себя

1. Установите Node.js версии 22.12 или новее (LTS с nodejs.org).
2. Откройте папку проекта в терминале (в Windows: правый клик по папке → «Открыть в терминале»).
3. Один раз выполните `npm install`.
4. Запустите `npm run dev` и откройте в браузере адрес, который появится (обычно http://localhost:4321).

Сборка для выкладки: `npm run build` — готовый сайт появится в папке `dist`.

## Где лежит контент

| Что | Где | Формат |
| --- | --- | --- |
| Шоу | `src/content/events/` | один файл `.md` на шоу; имя файла = адрес страницы |
| Комики | `src/content/comedians/` | один файл `.md` на комика; текст файла — био |
| Фото из клуба | `src/content/gallery.json` | список; первые 7 видны на главной |
| Видео | `src/content/videos.json` | список ссылок на VK Видео / Rutube / YouTube |
| Настройки клуба | `src/content/settings.json` | адрес, телефон, ссылки, тексты, включение разделов |
| Open mic, «О клубе», реквизиты | `src/content/settings.json` → `openMic`, `about` | шаги, правила, вопросы-ответы, имя ведущего; абзацы истории клуба |

Всё это редактируется через админку — она пишет в те же файлы (см. ниже).

### Поля шоу

```yaml
title: Стендап-концерт
format: standup        # standup | openmic | test | solo
start: 2026-10-24T18:30  # время по Перми
priceFrom: 1000
ticketUrl: https://perm.qtickets.events/...
seats: ok              # ok | few (мало мест) | out (sold out)
status: plan           # plan | moved (перенесено) | cancelled (отменено)
movedFrom: 2026-10-18T18:30   # только для переноса
cancelReason: ...             # только для отмены, по желанию
comedians: [artem-dyldin, nikolay-budrin]
published: true        # false — черновик, на сайте не виден
```

Прошедшие шоу сами пропадают из афиши при следующей сборке.

### Разделы сайта

В `settings.json` → `sections` можно выключить раздел (`false`): комики, фото, open mic, факты на главной, видео. Выключенный раздел пропадает из меню и с главной, данные не удаляются.

## Сейчас в проекте тестовые данные

Шоу в `src/content/events/` — **тестовые** (пометка «[Тестовое шоу]» в описании), чтобы показать все состояния: мало мест, перенос, отмена, sold out, черновик. Перед запуском их нужно заменить настоящими.

## Админка

Код — в папке `admin/`, подробности запуска — `admin/DEPLOY.md`, устройство защиты — `SECURITY.md`.

- `npm run admin:dev` — админка у себя на компьютере (http://localhost:8787), правки сразу пишутся в файлы проекта;
- `npm run admin:test` — тесты защиты;
- `npm run admin:build` — сборка для Yandex Cloud Functions.

В Windows PowerShell вместо `npm` пишите `npm.cmd`.

## Превью ссылок

Картинки, которые видны при отправке ссылки в Telegram/VK, собираются сами при сборке: общая (`/og/default.png`), для каждого шоу и каждого комика. Делать их вручную не нужно.

## Политика конфиденциальности

`src/pages/privacy.astro` — рабочий шаблон. Перед запуском заполнить поля в [скобках] (оператор, почта) и показать юристу.

## Структура

- `src/content.config.ts` — схемы данных (по ним же будет строиться админка)
- `src/styles/tokens.css` — цвета, шрифты, отступы (дизайн-система)
- `src/components/` — блоки страниц
- `src/pages/` — страницы сайта
- `src/lib/` — даты по Перми, работа с афишей, настройки
